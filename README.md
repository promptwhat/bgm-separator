# BGM OFF

Public browser app by Prompt_what. This repository contains only the compiled website and its public model/runtime assets. Videos stay on the user device.

[Open BGM OFF](https://promptwhat.github.io/bgm-separator/) · [Usage and attribution](https://promptwhat.github.io/bgm-separator/about.html)

Dialogue/effects mode removes music where two models agree: BandIt v2 (code Apache-2.0; weights and the converted files in models/ CC BY-SA 4.0, see models/NOTICE-BANDIT.txt) and TIGER-DnR (code MIT, weights Apache-2.0). See models/ and licenses/ for third-party license notices. No training samples, source videos, or private project files are included.
